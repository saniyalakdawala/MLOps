# MLOps Agile Demo - Experiment 1: Agile and Scrum

Simulates a 1-week Scrum Sprint for an Iris flower classifier (MLOps project).

## Structure
```
MLOps_Agile_Demo/
├── data/        # iris.csv (your dataset) and iris_clean.csv (output)
├── src/         # iris_demo.py
├── models/      # saved Decision Tree model
├── docs/        # Scrum artifacts and accuracy report
├── requirements.txt
└── README.md
```

## Run
```
pip install -r requirements.txt
python src/iris_demo.py
```
Expected output: Accuracy around 0.90 - 1.0 (printed along with a confusion matrix and report).

## Scrum artifacts (docs/)
Scrum_Team, Product_Backlog, Sprint_Planning, Daily_Scrum, Sprint_Review, Sprint_Retrospective, Sprint_Increment, Accuracy_Report.
