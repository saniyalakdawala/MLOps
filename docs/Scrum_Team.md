# Scrum Team

| Student   | Scrum Role    | Responsibilities |
|-----------|---------------|------------------|
| Student 1 | Product Owner | Defines requirements, prioritizes work, maintains Product Backlog, accepts completed work |
| Student 2 | Scrum Master  | Conducts Sprint Planning and Daily Scrum, removes blockers, ensures Scrum rules are followed |
| Student 3 | ML Engineer   | Selects algorithm, trains model, improves performance, saves trained model |
| Student 4 | Data Engineer | Collects dataset, cleans data, splits dataset, prepares features |
| Student 5 | Tester        | Tests model, verifies prediction accuracy, reports bugs, validates output |

*If only one student performs the experiment, they assume all five roles.*
